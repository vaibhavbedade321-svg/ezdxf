Add a runtime divergence report to griffe.

`griffe check --runtime PACKAGE` loads a package through both agents and reports their disagreements: text goes to standard error, a JSON array to standard output with `--json`, and it exits 1 exactly when divergences exist. `griffecli.main(argv)` returns the exit code.

Public API in `griffe`: `load_both`, taking loading options like `search_paths`, returns independent static and dynamic models. `find_divergences(static, dynamic)` yields `Divergence` records with `kind`, `object_path`, `static_value` and `dynamic_value`, `as_dict()` carrying at least those fields JSON-serializably, and `explain()`, one line naming the path, the kind's string value and both values. Members `MEMBER_MISSING`, `KIND_MISMATCH`, `PARAMETER_MISSING`, `PARAMETER_ORDER`, `PARAMETER_KIND`, `PARAMETER_DEFAULT`, `ANNOTATION`, `SIGNATURE_ERASED`, `EXPORTS_MISMATCH`, `BASES_MISMATCH` of `DivergenceKind` carry descriptive string values. `object_path` is the dotted path, parameter divergences appending the parameter name as `pkg.func(b)`; a missing side's value is `None`.

Not divergences: dunder attributes the interpreter itself injects, `typing.TYPE_CHECKING` names, imported names seen as module members, annotation-only declarations, dataclass-generated methods, properties. An `ANNOTATION` divergence needs an annotation on both sides and compares only when both agents recovered one; where a single agent has it and the other does not — as on a parameter or a dataclass field whose default leads the dynamic agent to drop the annotation — there is nothing to compare and no divergence, whichever side is missing. Signature erasure to `*args, **kwargs` yields one `SIGNATURE_ERASED`, `functools.wraps` nothing, partial rewrites report per parameter. Runtime-built classes are `KIND_MISMATCH`; conditionally absent members and names user code injects are `MEMBER_MISSING`; decorator-rewritten bases are `BASES_MISMATCH`, comparing base names, ignoring implicit `object`; import-time `__all__` extensions are `EXPORTS_MISMATCH`. Nested classes compare recursively.
