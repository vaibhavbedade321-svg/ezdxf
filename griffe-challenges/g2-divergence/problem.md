Griffe models a package both statically and dynamically but never compares the two, so a public API the source declares one way while import produces another goes unnoticed. Add a runtime divergence report that finds and surfaces those disagreements.

`griffe check --runtime PACKAGE` loads a package through both agents and reports their disagreements: text goes to standard error, a JSON array of each divergence's `as_dict()` to standard output with `--json`, and it exits 1 exactly when divergences exist. `griffecli.main(argv)` returns the exit code.

In `griffe`, `load_both` takes loading options like `search_paths` and returns independent static and dynamic models. `find_divergences(static, dynamic)` yields `Divergence` records with `kind`, `object_path`, `static_value` and `dynamic_value`, `as_dict()` carrying at least those fields JSON-serializably, and `explain()`, one line naming the path, the kind's string value and both values. Members `MEMBER_MISSING`, `KIND_MISMATCH`, `PARAMETER_MISSING`, `PARAMETER_ORDER`, `PARAMETER_KIND`, `PARAMETER_DEFAULT`, `ANNOTATION`, `SIGNATURE_ERASED`, `EXPORTS_MISMATCH`, `BASES_MISMATCH` of `DivergenceKind` carry descriptive string values. `object_path` is the dotted path, parameter divergences appending the parameter name as `pkg.func(b)`; a missing side's value is `None`.

Not divergences: the attributes the interpreter itself injects, namely `__all__`, `__annotations__`, `__builtins__`, `__cached__`, `__dict__`, `__doc__`, `__file__`, `__firstlineno__`, `__loader__`, `__module__`, `__name__`, `__package__`, `__path__`, `__spec__`, `__static_attributes__` and `__weakref__`; the methods `@dataclass` generates, namely `__init__`, `__repr__`, `__eq__`, `__hash__`, `__match_args__`, `__dataclass_fields__`, `__dataclass_params__`, `__replace__`, the ordering methods `__lt__`, `__le__`, `__gt__` and `__ge__`, and the frozen methods `__setattr__` and `__delattr__`; `typing.TYPE_CHECKING` names, imported names seen as module members, annotation-only declarations, properties. A dunder outside those sets, injected by user code, is still a `MEMBER_MISSING`. An `ANNOTATION` divergence needs an annotation on both sides and compares only when both agents recovered one; where a single agent has it and the other does not - as on a parameter or a dataclass field whose default leads the dynamic agent to drop the annotation - there is nothing to compare and no divergence, whichever side is missing. Signature erasure to `*args, **kwargs` yields one `SIGNATURE_ERASED`, `functools.wraps` nothing, partial rewrites report per parameter. Runtime-built classes are `KIND_MISMATCH`; conditionally absent members and names user code injects are `MEMBER_MISSING`; decorator-rewritten bases are `BASES_MISMATCH`, ignoring implicit `object`; import-time `__all__` extensions are `EXPORTS_MISMATCH`. Nested classes compare recursively, and so do submodules, including a submodule reached as an imported member of its parent.
