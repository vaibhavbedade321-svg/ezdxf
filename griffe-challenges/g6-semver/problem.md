Add a semantic version bump recommendation to griffe.

Griffe can list the breaking changes between two versions of a package, but it never turns that into a release decision, and it never notices backward-compatible additions at all. Release tooling wants a single answer: is the next version a major, minor or patch bump.

`recommend_bump(old, new)`, importable from `griffe` alongside `Bump`, `ChangeKind` and `BumpReport`, takes two loaded package models and returns a `BumpReport`. Objects are compared by their path relative to the package name, and nested members of classes and submodules are compared too. `bump_between(package, old_path, new_path, **load_options)` is a convenience that loads the package from each search path and compares the two.

A breaking change or a public object that left the public surface recommends `Bump.MAJOR`. A public object added, or a public function whose signature gained only optional parameters, a new variadic, or an already-present required parameter relaxed to optional, all without breaking callers, recommends `Bump.MINOR`. Anything else, including private additions and docstring-only edits, recommends `Bump.PATCH`. Deleting a public object, or changing its kind between function, class and attribute, is caught by the breaking-change detector and reported only as `BREAKING`, never a second time as a removal; the `REMOVED` kind and `removals` list instead capture a public object that leaves the surface without the detector flagging it, such as a name dropped from `__all__` while still defined.

Each change is a `Change` record with a `kind` (a `ChangeKind`, one of `BREAKING`, `REMOVED`, `ADDED` and `EXPANDED`), a `path` and a short `detail`. `BumpReport` carries `bump`, a `breaking` list and a `changes` list sorted by path then kind. It exposes `additions`, `removals` and `expansions` path lists, a `counts` mapping from change-kind names to counts omitting empty kinds, a `changes_of_kind(kind)` filter, `render_text()` and `render_markdown()` renderers, `gated_by(level)` telling whether the recommendation meets a threshold, `explain()` and `str()` giving a one-line summary, `bump_version(version)` returning a `major.minor.patch` version bumped by the level with any suffix dropped and raising `ValueError` on a malformed version, and a JSON-serializable `as_dict()` carrying `bump`, `breaking`, `additions`, `removals`, `expansions` and a `changes` list whose entries carry each change's kind.

`griffe semver PACKAGE --old OLD --new NEW` prints the recommended level with its changes, the same dictionary as JSON with `--json`, Markdown with `--markdown`, or with `--bump VERSION` that version bumped. `--fail-on LEVEL` exits nonzero when the recommendation meets that level. The `Bump` and `ChangeKind` members carry lowercase string values.
