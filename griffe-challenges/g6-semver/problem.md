Griffe finds breaking changes between two package models but never turns them into a bump decision.

`recommend_bump(old, new, ignore=())`, importable from `griffe` with `Bump`, `ChangeKind` and `BumpReport`, compares two loaded models and returns a `BumpReport`. Objects compare by exported path relative to the package name, not definition site; nested members of classes and submodules compare too, including inside a newly added or re-exported container. Names in `ignore`, each matched against a whole first path segment, are excluded entirely, breakage included. `bump_between(package, old_path, new_path, ignore=(), **load_options)`, also importable from `griffe`, loads the package from each search path, forwarding load options to both, then compares them.

A breaking change or a public object leaving the surface recommends `Bump.MAJOR`. A public object added, one gaining a compatible capability, or one newly carrying a decorator named `deprecated`, wherever defined, recommends `Bump.MINOR`. Anything else recommends `Bump.PATCH`. Compatible gains are a signature that only added optional parameters or a variadic or relaxed a required parameter to optional, a class that only added bases, and an object declaring its own return or type annotation where it had none; a parameter gaining, losing or changing one never counts. Every breakage is its own `BREAKING` entry: dropping two parameters reports it twice. Deleting a public object or changing its kind is `BREAKING` under the exported path, never also a removal, and a breaking object is never also `EXPANDED` or `DEPRECATED`; `REMOVED` captures an object leaving the surface with no breakage, such as a name dropped from `__all__` while still defined.

Each change exposes a `kind` (`BREAKING`, `REMOVED`, `ADDED`, `EXPANDED` or `DEPRECATED`), a `path`, a non-empty `detail` and a `severity` for the level it alone forces. `BumpReport` carries `bump`, the `breaking` list and a `changes` list sorted by path then kind. It exposes `additions`, `removals`, `expansions` and `deprecations` path lists, `counts` mapping kind values to nonzero counts, a `changes_of_kind(kind)` filter, and `changelog()` mapping each first path segment to its list of changes. `render_text()` and `render_markdown()` name the level and list the changed paths; `explain()` and `str()` give the same one-line summary naming the level. `gated_by(level)` takes a `Bump` member or its value and holds when the recommendation meets or exceeds it; `bump_version(version)` bumps a `major.minor.patch` version whose parts carry no leading zero, drops a suffix introduced by `-` or `+`, and raises `ValueError` on anything else; and JSON-serializable `as_dict()` carries `bump`, `additions`, `removals`, `expansions`, `deprecations` and `counts`, plus `breaking` and `changes` lists of entries carrying kind, path and detail.

`griffe semver PACKAGE --old OLD --new NEW` prints the level with its changes, JSON with `--json`, Markdown with `--markdown`, or `--bump VERSION` bumped, exiting nonzero on a malformed version. `--fail-on LEVEL` exits nonzero exactly when `gated_by(LEVEL)` holds, in any output mode, and repeatable `--ignore NAME` shapes the comparison itself, so its recommendation drives both the bump and the gate. Other commands' loading options reach both loads. Enum members carry lowercase string values. `griffecli.main(argv)` returns the exit code.
