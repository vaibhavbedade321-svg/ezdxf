Griffe finds breaking changes between two loaded package models but never turns them into a major, minor or patch decision, nor notices backward-compatible additions.

`recommend_bump(old, new, ignore=())`, importable from `griffe` with `Bump`, `ChangeKind` and `BumpReport`, compares two loaded models and returns a `BumpReport`. Objects compare by exported path relative to the package name, not definition site; nested members of classes and submodules, including containers reached through a re-export, compare too. Names in `ignore`, matched on the first path segment, are excluded entirely, breaking changes included. `bump_between(package, old_path, new_path, ignore=(), **load_options)`, also importable from `griffe`, loads the package from each search path, forwarding load options to both, and compares them.

A breaking change or a public object that left the surface recommends `Bump.MAJOR`. A public object added, one gaining a backward-compatible capability, or one newly carrying a decorator named `deprecated`, wherever defined, recommends `Bump.MINOR`. Anything else recommends `Bump.PATCH`. Compatible gains are a signature that only added optional parameters or a variadic or relaxed a required parameter to optional, a class that only added bases, and an object declaring its own return or type annotation where it had none, which a parameter gaining, losing or changing one never is. Every breakage becomes its own `BREAKING` entry, so dropping two parameters reports it twice. Deleting a public object or changing its kind is reported once as `BREAKING` under the exported path, never also as a removal, and a breaking object is never also `EXPANDED` or `DEPRECATED`; `REMOVED` captures an object that leaves the surface with no breakage reported, such as a name dropped from `__all__` while still defined.

Each change exposes a `kind` (`BREAKING`, `REMOVED`, `ADDED`, `EXPANDED` or `DEPRECATED`), a `path`, a non-empty `detail`, and a `severity` for the level it alone forces. `BumpReport` carries `bump`, the `breaking` list and a `changes` list sorted by path then kind. It exposes `additions`, `removals`, `expansions` and `deprecations` path lists, `counts` mapping kind values to nonzero counts, a `changes_of_kind(kind)` filter, and `changelog()` grouping changes by first path segment. `render_text()` and `render_markdown()` name the level and list the changed paths; `explain()` and `str()` give the same one-line summary naming the level. `gated_by(level)` takes a `Bump` member or its value and is true when the recommendation meets or exceeds it; `bump_version(version)` bumps a `major.minor.patch` version whose parts carry no leading zero, dropping a suffix introduced by `-` or `+` and raising `ValueError` on anything else; and JSON-serializable `as_dict()` carries `bump`, `breaking`, `additions`, `removals`, `expansions`, `deprecations`, `counts` and `changes` entries with each change's kind, path and detail.

`griffe semver PACKAGE --old OLD --new NEW` prints the level with its changes, JSON with `--json`, Markdown with `--markdown`, or `--bump VERSION` bumped, exiting nonzero on a malformed version. `--fail-on LEVEL` exits nonzero exactly when `gated_by(LEVEL)` holds, in any output mode, and repeatable `--ignore NAME` shapes the comparison itself, so its recommendation drives both the printed bump and the gate. The loading options the other commands accept are passed through to both loads. Enum members carry lowercase string values.
