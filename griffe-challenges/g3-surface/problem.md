Add a public-surface audit for Griffe.

`audit_surface(package)`, importable from `griffe` with `SurfaceIssueKind`, resolves re-export chains and returns a report whose issues expose `kind`, `public_path` and a human-readable `details` string. Categories: `PRIVATE_ORIGIN`, a public name defined in a private module, details naming the definition and, if multiply exposed, the canonical path; `DANGLING_EXPORT`, an `__all__` entry resolving to nothing; `UNDOCUMENTED`, a public module, class or function lacking a docstring; `DUPLICATE_EXPOSURE`, reported once at the canonical path with the other paths in details; `INCONSISTENT_ALL`, a name a module defines, without a leading underscore, that its own `__all__` omits; imported names are not flagged, since omission from `__all__` is what makes them private; `PRIVATE_LEAK`, a public signature or base class referencing a private-module object that is not itself publicly reachable; `MUTABLE_DEFAULT`, a public function or method whose signature carries a list, dict or set default argument, empty or not, in statically parsed and dynamically inspected packages alike. A public class reached through a re-export is traversed so its own public members are audited under that public path, while a private origin is reported once at the re-export entry. Objects that are private because of a leading-underscore name or an enclosing private module yield nothing, but dunder methods such as `__call__` count as public and are audited like any other member.

Issues are sorted by category name then path, and `issues_of_kind(kind)` lists one category's issues in that same order. `counts` is keyed by issue-kind names, the `SurfaceIssueKind` member names such as `UNDOCUMENTED`, and covers only kinds with issues. `canonical_paths` maps each definition path to the public path with the fewest segments, ties broken alphabetically. `render_text()` and `render_markdown()` group issues by category, in the same category order as `issues`, under a heading built from that category's `SurfaceIssueKind` value, and list the `public_path` of every issue in the group; both also give each category its count, and both say clean when empty. JSON-serializable `as_dict()` carries `package`, the issues and both mappings. The report also offers `filter(*kinds)` returning a report over only those categories, `affected_paths` listing the distinct issue paths sorted, and `summary()` naming the package.

`griffe api PACKAGE` exits 1 when issues exist and 0 otherwise. The default text report and `--markdown` both write to standard error and only when issues exist, so a clean run prints nothing there; `--json` always writes the JSON report to standard output, carrying an empty issue list on a clean run. Repeatable `--fail-on` takes hyphenated category names and, when given, restricts the nonzero exit to runs where any one of the selected categories is present.
