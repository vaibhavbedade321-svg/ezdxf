Add a public-surface audit for Griffe.

`audit_surface(package)`, importable from `griffe` with `SurfaceIssueKind`, resolves re-export chains and returns a report. Each issue carries a `kind`, a `public_path` and a `details` string.

Flag a public name defined in a private module as `PRIVATE_ORIGIN`, details naming the definition and, when it is multiply exposed, the canonical path. Flag an `__all__` entry resolving to nothing as `DANGLING_EXPORT`, and a public module, class or function lacking a docstring as `UNDOCUMENTED`. Report an object reachable by several public paths once as `DUPLICATE_EXPOSURE`, at the canonical path, with the others in details. Flag a name a module defines without a leading underscore that its own `__all__` omits as `INCONSISTENT_ALL`; imported names are not flagged, since omission from `__all__` is what makes them private. Flag a public signature or base class referencing a private-module object that is not itself publicly reachable as `PRIVATE_LEAK`. Flag a public function or method whose signature carries a list, dict or set default as `MUTABLE_DEFAULT`, empty or not, in statically parsed and dynamically inspected packages alike.

A public class reached through a re-export is traversed so its own public members are audited under that public path, while a private origin is reported once at the re-export entry. Leading-underscore names and objects inside private modules yield nothing, but dunder methods such as `__call__` count as public and are audited like any other member.

Issues are sorted by category name then path, and `issues_of_kind(kind)` lists one category's issues in that same order. `counts` is keyed by issue-kind names, the `SurfaceIssueKind` member names such as `UNDOCUMENTED`, and covers only kinds with issues. `canonical_paths` maps each definition path to the public path with the fewest segments, ties broken alphabetically. `render_text()` and `render_markdown()` group issues by category, in the same category order as `issues`, under a heading built from that category's `SurfaceIssueKind` value, and list the `public_path` of every issue in the group; both also give each category its count, and both say clean when empty. `as_dict()` returns a JSON-serializable payload with `package`, `issues`, `counts` and `canonical_paths`. Also provide `filter(*kinds)`, returning a report over only those categories, `affected_paths`, the distinct issue paths sorted, and `summary()`, naming the package.

`griffe api PACKAGE` exits 1 when issues exist and 0 otherwise. The default text report and `--markdown` both write to standard error and only when issues exist, so a clean run prints nothing there; `--json` always writes the JSON report to standard output, carrying an empty issue list on a clean run. Repeatable `--fail-on` takes hyphenated category names and, when given, restricts the nonzero exit to runs where any one of the selected categories is present.
