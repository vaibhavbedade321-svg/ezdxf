Add a triangulation engine to `trimesh.creation.triangulate_polygon`, selected with `engine="delaunay"`. It has to work on the required dependencies alone, so it can reach for neither an optional triangulation package nor scipy, and it is the engine picked automatically when none of the optional ones are installed, so a bare install stops raising.

It returns counter-clockwise triangles which exactly cover the polygon. By default nothing is invented: the vertices are exactly the ring vertices, each of them once, and every one gets used. Rings may be wound either way, and a polygon enclosing no area yields no triangles. Every ring segment is covered by edges of the result, and any edge which is not part of one is locally Delaunay.

Two optional quality targets, `min_angle` in degrees and `max_area`, add vertices until no triangle is sharper or bigger than asked, leaving the boundary exactly where it was. A `min_angle` outside `0 < min_angle <= 30` is rejected, as is a `max_area` which is not positive. The other engines reject both targets, as does pairing either with `force_vertices`.
