Add a triangulation engine to `trimesh.creation.triangulate_polygon`, selected with `engine="delaunay"`, that is built into the library. It has to work on the required dependencies alone, reaching for neither an optional triangulation package nor scipy, and it is the engine picked automatically when none of the optional ones are installed, so a bare install stops raising.

It returns vertices and counter-clockwise triangle indexes covering the polygon exactly once, never overlapping, never crossing a ring or entering a hole. By default nothing is invented: the vertices are exactly the ring vertices, each of them once, and every one gets used. Rings may be wound either way. Every ring segment is covered by edges of the result, and any edge that is not part of one is locally Delaunay, meaning that where two triangles share such an edge neither circumcircle strictly contains the opposite vertex of the other.

Two optional quality targets, `min_angle` in degrees and `max_area`, add vertices until no triangle is sharper or bigger than asked, leaving the boundary exactly where it was. Other engines reject them, as does pairing them with `force_vertices`, and out-of-range values raise.
